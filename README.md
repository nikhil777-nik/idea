## Auto Cursor Replay - Chrome Extension (Manifest V3)

Automatically move a visible virtual cursor inside Chrome by replaying recorded movement sequences smoothly.

### Features
- **Virtual Cursor Overlay**: Smooth requestAnimationFrame keyframe movement inside Chrome webpages.
- **Recording & Playback**: Record movements, clicks, double clicks, and scroll events.
- **Speed Control**: Replay from 0.25x to 4.0x.
- **Profiles Management**: Save, rename, delete, and switch between movement profiles.
- **JSON Import/Export**: Backup and transfer recorded tracks.

### Installation
1. Open `chrome://extensions` in Chrome.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this directory.
